# Professional C++ Study Repository

My notes, examples, exercises, and projects while working through *Professional C++*.

## Layout

- `examples/` contains code and notes that follow the book.
- `exercises/` contains my solutions to the chapter exercises.
- `projects/` contains larger, standalone projects.

Each C++ source file is intended to be built independently unless its directory provides a Makefile for a group of files. Generated binaries and build artifacts are excluded from version control.
